# 浏览器字体与网络

浏览器插件1.5.4的已签名runtime只附带DejaVu字体。网页上的中文按钮可能显示成方框；网页图片内的中文正常并不能证明字体齐全。

本设备的recovery已经提供`/twres/fonts`，其中包含文泉驿微米黑和多语种Noto字体。云端补丁在浏览器启动前创建专用字体挂载点，将该目录只读提供到`/usr/share/fonts/recovery`。Fontconfig会在原有字体目录下发现这组字体；插件原有字体与已签名runtime.xz不变。只暴露这一组字体数据，不增加分区或共享存储访问。

这项修改应通过新启动的WebKit进程验证。已运行的进程临时挂入字体后，刷新不一定重建字体缓存。验证时需要对照同一中文页面和沙箱中的实际字体访问，不能只测试英文内置页。

RPC通道使用同一组经过类型和所有者检查的FIFO节点，并串行化UI和任务线程的访问；显式关闭命令通道的界面不会被自动重新启用。

网络仍优先使用DHCP DNS。单个DHCP服务器时，国内和国际备用地址同时进入Bionic支持的前三项；多个DHCP服务器仍按原顺序保留。浏览器的独立解析配置也读取net.dns3和net.dns4。下载保留Gitee、GitHub镜像及原始签名载荷的回退路径。

`AERA network compatibility probe`独立工作流记录云端节点的地区观察、镜像与原始载荷的HTTPS/大小/SHA256检查、公共DNS响应。该结果只覆盖对应Linux IPv4云端路径，不等同于境外手机、所有国家或IPv6-only网络均已通过。
